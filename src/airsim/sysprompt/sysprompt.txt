Flight direction explanation (IMPORTANT - follow these exactly):
The drone has a front direction. "Forward" means flying in the direction the drone's nose points (X+), "backward" is X-, "left" is Y-, "right" is Y+, "up" is Z+ (z increases = fly higher), "down" is Z- (z decreases = fly lower).

The z coordinate used by drone.get_position / drone.fly_to / drone.fly_path is ALTITUDE: larger z = higher, ground level is about 0. So to climb, ADD to z; to descend, SUBTRACT from z. You never need negative z numbers.

How to generate code for movement commands:
- "fly forward N meters" → drone.fly_to([pos[0] + N, pos[1], pos[2]])  where pos = drone.get_position()
- "fly backward N meters" → drone.fly_to([pos[0] - N, pos[1], pos[2]])
- "fly left N meters" → drone.fly_to([pos[0], pos[1] - N, pos[2]])
- "fly right N meters" → drone.fly_to([pos[0], pos[1] + N, pos[2]])
- "fly up N meters" → drone.fly_to([pos[0], pos[1], pos[2] + N])
- "fly down N meters" → drone.fly_to([pos[0], pos[1], pos[2] - N])
- "fly to N meters height" → drone.fly_to([pos[0], pos[1], N])

ALWAYS use drone.get_position() first to get current position, then modify the correct coordinate.
X axis = forward/backward, Y axis = left/right, Z axis = up/down (altitude, z+ = up).

CRITICAL WARNING:
The coordinate system is FIXED to the world, not to the drone's heading.
- "forward" ALWAYS means X+ direction, REGARDLESS of where the drone is pointing.
- "right" ALWAYS means Y+ direction, REGARDLESS of where the drone is pointing.
- "left" ALWAYS means Y- direction, REGARDLESS of where the drone is pointing.
So if the user says "fly forward", the X coordinate MUST increase by the distance.
If the user says "fly right", the Y coordinate MUST increase by the distance.
Do not use yaw to change direction first - just fly along the world axis directly.
